# Выпуск v1.2 — заготовка

> Это **черновик**, а не выпущенная версия. Сюда по ходу работы вносится то,
> что уже попало во внутренний тестовый образ, но ещё не опубликовано. Когда
> накопленное будет проверено, этот файл станет описанием выпуска.
>
> Опубликованные версии — на странице
> [выпусков](https://github.com/mamaich/GammaOSNext-RG52mini/releases).

Основа прежняя: GammaOS Next Core (Android 14) для **AISLPC RG52 Mini** на
Rockchip RK3562. Здесь только то, что изменилось после
[v1.1](release-v1.1.md).

## Что уже в тестовом образе

- **Ход прошивки виден на экране.** При обновлении по воздуху панель гасла на
  всё время записи. Виноват `bootanim`: его поднимает SurfaceFlinger, когда
  умирает system_server, и он перекрывает наш экран прогресса. Первая попытка
  гасить анимацию не сработала — она случалась раньше, чем init успевал
  обработать `ctl.stop zygote` (в замерах разрыв доходил до 13 секунд), а флаг
  выхода SurfaceFlinger сбрасывает обратно. Теперь дожидаемся, пока
  `init.svc.zygote` станет `stopped`, гасим после этого и повторяем раз в
  секунду, пока идёт запись. **Требует проверки на устройстве.**

## Обязательно сделать перед публикацией

- **Приложить OTA-пакет.** Это главное, ради чего копился выпуск: обновляться
  им можно начиная с v1.1, где механизм уже есть. Пакет собирается
  `device/rg52mini/tools/make-ota.sh` с ключами `-l 9 -z` (сильное сжатие и zip
  для меню обновления на устройстве). К выпуску приложить оба варианта —
  распакованные `manifest.json` + `system.img.xz` для установки через adb и zip
  для меню, — и написать в описании инструкцию:

      adb push manifest.json system.img.xz /data/gammaos_ota/package/
      adb shell setprop sys.gammaos.ota.autoinstall 1
      adb shell start gammaos-ota

  Весь круг занимает около пяти минут, карту вынимать не нужно.

## Что обсуждалось, но не сделано

Это не обещания, а список того, к чему имеет смысл вернуться.

- **Размер архива подошёл к пределу вплотную.** Zip для v1.1 дал 1,993 ГиБ при
  пределе GitHub в 2 ГиБ — запас всего 7,6 МБ. Следующий выпуск в zip почти
  наверняка уже не влезет, и придётся переходить на `xz` (он давал около
  1,7 ГиБ) или делить архив на части.
- **Свежий драйвер Mali.** Из-за версии `g7p1-01bet0` не запускаются игры на
  Vulkan. В сборках `g13p0` и новее проблемных функций нет вовсе, но
  android-версию для Mali-G52 найти пока не удалось: в четырёх проверенных
  прошивках лежит один и тот же `g7p1`. Отсеивать кандидатов можно одной
  строкой, не сканируя файл целиком:

      strings libGLES_mali.so | grep -oE 'g[0-9]+p[0-9]+-[0-9a-z]+'

- **Настройки lmkd.** Проверено и решено не трогать: симптома нет, убиваются
  только кэшированные процессы. Если понадобится — рычаги и способ подбирать их
  без пересборки описаны в [02-план.md](02-план.md).
- **Зависание RetroArch при запуске из nano.** Наблюдалось один раз, похоже на
  беду самого RetroArch. Если повторится — смотреть в сторону Vulkan.
- **Заготовка сторожа пустого экрана** лежит в `device/rg52mini/extras/` и в
  образ не входит.
