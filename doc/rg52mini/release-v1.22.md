# Выпуск v1.22 (заготовка)

GammaOS Next (LineageOS 21 / Android 14) для карманной консоли **AISLPC RG52 Mini**
на Rockchip RK3562. Здесь перечислено то, что изменилось после
[v1.21](release-v1.21.md).

## Из предложений к GammaOS Next

Правки взяты из запросов на слияние в
[TheGammaSqueeze/GammaOSNextDistribution-14](https://github.com/TheGammaSqueeze/GammaOSNextDistribution-14/pulls),
которые автор GammaOS Next пока не принял.

- **Яркость больше не сбивается при загрузке в nano.** Яркость, выставленная в
  Android не ползунком, а напрямую (через adb или стороннее приложение), не
  доходила до nano: после перезагрузки nano возвращал прежний уровень и
  записывал его обратно в Android. Теперь последняя выставленная яркость
  сохраняется при любом способе её смены. После обновления консоль один раз
  возьмёт уровень, который последним запомнил nano.
- **Усилитель динамика больше не остаётся включённым на час после загрузки в
  nano.** Чтобы звук не пропадал в мастере первой настройки, nano держит
  усилитель включённым целый час после каждого звука. Теперь, когда первая
  настройка пройдена, через несколько секунд тишины усилитель, как и в
  Android, выключается.
- **В режиме nano работает статистика использования приложений.** Программы
  учёта игрового времени ничего не видели, пока консоль загружена в nano, а при
  следующей загрузке в Android вся накопленная история получала одно и то же
  время.
